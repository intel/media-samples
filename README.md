# Intel® Media Samples

This repository contains media sample applications for Intel® Processor Graphics.

## Samples Overview

Samples in this repository:
* D3D12 VPBlit LUT Sample - Demonstrates video processing with **1D and 3D LUT (Look-Up Table) transforms** using the
[D3D12 Video Processing LUT Compound API](https://github.com/microsoft/DirectX-Specs/blob/master/d3d/D3D12_Video_Processing_LUT.md).

## Getting Started

### Clone repository
    git clone https://github.com/intel/media-samples
    cd media-samples

### Build
Refer to each sample's folder for build instructions.
